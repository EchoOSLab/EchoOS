## 2. 实验设计（硬件到位后执行）

### 2.1 硬件

- NUCLEO-H743ZI2（Cortex-M7 @480 MHz，D-Cache + TCM）；
- 逻辑分析仪（≥24 MHz，8 通道）接一个 GPIO；
- SWD 调试器（板载 ST-Link）；
- 可选：电流探头/示波器。

### 2.2 固件

在 W5 的 3 节点图上扩展为 H7 版本：

```
bsp/echo-bsp-nucleo-h743zi/
  ├── DWT 时基（W6）
  ├── UART trace（待实现）
  ├── DWT 直方图打点（echo-bench）
  └── actuator 任务里翻转 GPIO（逻辑分析仪测周期）
```

### 2.3 对照组

| 组 | 内容 | 目的 |
| --- | --- | --- |
| **A · 基线** | 裸机定时器 ISR 翻转 GPIO，1 kHz | 硬件与测量的噪声底 |
| **B · EchoOS** | 循环执行体调度 3 节点图，actuator 翻转 GPIO | 调度/中断/临界区引入的抖动 |

**必须同时测 A 和 B**；只报 B 的数字无法区分"OS 抖动"与"板子噪声"。

### 2.4 指标

| 指标 | 采集方式 |
| --- | --- |
| 周期抖动分布 P50/P99/P99.9/max | 逻辑分析仪周期直方图 + DWT |
| ISR 延迟 | DWT 在 ISR 入口/出口打点 |
| 槽位超限 / deadline miss | 调度器计数器 + trace |
| 72h 稳定性 | 连续运行，记录 miss/复位/内存高水位 |
| TCM 对比 | 控制律在 ITCM vs 普通 RAM 的抖动分布 |

### 2.5 步骤

1. 烧录组 A，捕获 ≥10⁶ 个周期，导出 CSV；
2. 烧录组 B，同样捕获；
3. 每组重复 3 次（不同上电/温度）；
4. 计算 `P99−P50`、`P99.9−P50`、max、miss 率；
5. 72h soak；
6. 把 CSV + 构建指纹 + 调度表写入 `evidence/`。
